# Spring Boot — Estudos

Repositório destinado ao estudo e à prática de recursos e funcionalidades do Spring Boot, com pequenos projetos independentes para experimentar conceitos, testar implementações e consolidar conhecimentos.

## Conteúdos

- Paginação
- Tratamento de exceções
- Validações
- DTOs
- Relacionamentos JPA
- Consultas personalizadas
- Projeções

## Tecnologias

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven

## Objetivo

Reunir exemplos práticos e anotações para consulta, revisão e aprofundamento dos conhecimentos em Spring Boot.
